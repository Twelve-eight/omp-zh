## 约定

- 命令示例统一写作 `omp`。如果你保留了 `omp-zh.exe` 这个文件名，请相应替换。
- 路径写作 `%USERPROFILE%\.omp\...`，在 macOS 与 Linux 上对应 `~/.omp/...`。
- 界面文字按 omp-zh 的中文写出，第一次出现时在括号中附上英文原文，方便对照官方版。
- 每章末尾的“相关文档”链接到上游 v18.13.3 的英文文档，那里有更完整的细节。

## 准确性

教程中的命令、参数、默认值和文件路径都对照过上游 v18.13.3 的源码、文档和实际的 `--help` 输出。omp 更新很快，新版本的行为可能与这里不同；遇到不一致时以 `omp --help` 和上游文档为准，也欢迎 [提交 issue](https://github.com/Twelve-eight/omp-zh/issues/new/choose) 指出。
